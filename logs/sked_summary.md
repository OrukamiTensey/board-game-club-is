# Підсумок сесії SKED (Structured Knowledge Elicitation Dialogue)

- **Проєкт:** Інформаційна система клубу настільних ігор (BoardClub IS)
- **Учасники діалогу:** Студент-проєктувальник (Оператор) & Діалогова LLM (Системний аналітик)
- **Ціль сесії:** Виявлення невизначеностей, усунення неперевірюваних формулювань, детермінація бізнес-правил перед формуванням SRS.

---

## 1. Виявлені невизначеності та прийняті рішення

| Предметна область | Початкова невизначеність | Прийняте рішення (Людина) |
| :--- | :--- | :--- |
| **Заставна політика** | Відсутність формули розрахунку застави та градації ігор за ризиком. | Запроваджено 3 категорії за ринковою вартістю: **A** (до 1000 грн), **B** (1000–2500 грн), **C** (> 2500 грн). Для звичайного гостя — 100% вартості; для члена клубу: кат. A — 0 грн, кат. B та C — 30% вартості. |
| **Статус клієнта** | Суб'єктивність присвоєння статусу «Постійний член клубу». | Автоматичний перехід після **5 успішних оренд** (повернутих вчасно і без пошкоджень). Скидання прогресу до 0 при факті пошкодження гри. |
| **Життєвий цикл гри** | Потреба у проміжних статусах перевірки. | Інспекція відбувається безпосередньо при клієнті на касі. Статуси екземпляра: `Доступний`, `Орендований`, `Потребує ремонту`, `Списаний`. Проміжний статус інспекції виключено як зайвий. |
| **Розподіл фонду** | Ризик вилучення ігор із залу під оренду додому. | Жорстке розділення фізичних екземплярів на **Прокатний фонд** та **Клубний фонд** (тільки для залу). |
| **Бронювання столів** | Довільні часові інтервали та суб'єктивне запізнення («не взяв слухавку»). | Слоти строго кратні 1 годині в межах робочого дня. Автоматичне зняття броні (No-Show) при запізненні на **20 хвилин** із повідомленням адміністратора. |
| **Фінансовий облік** | Ступінь автоматизації касових розрахунків. | Модель Pre-paid: повна оплата оренди та застави при видачі. Автоматичний розрахунок штрафів при прийомі (прострочення — 2x добової ціни/доба; пошкодження — 10/20/30/50/100% вартості за оцінкою адміна). |

## 2. Відхилені та скориговані припущення моделі

1. **Припущення:** Фіксована застава 500 грн для середньої категорії ігор (B).  
   *Коригування людини:* Затверджено єдиний процентний коефіцієнт — 30% від оціночної вартості як для категорії B, так і для C.
2. **Припущення:** Ручне призначення постійного членства адміністратором закладу.  
   *Відхилено людиною:* Запроваджено суворе алгоритмічне правило лічильника (5 бездоганних оренд) для усунення людського фактора.
3. **Припущення:** Введення окремого системного статусу `На перевірці`.  
   *Відхилено людиною:* Оскільки акт аудиту відбувається безпосередньо перед клієнтом біля стійки, статус змінюється атомарно.
4. **Припущення:** Нечіткий критерій очікування клієнта («дзвінок адміністратора»).  
   *Коригування людини:* Замінено на детермінований системний тайм-аут у 20 хвилин.

## 3. Межі системи (Scope)
- **In-Scope (Входить у поточний реліз):** Каталог настільних ігор та копій; моніторинг комплектності; планувальник столів із дискретними слотами; калькулятор чеків (оренда, застави, пеня, штрафи); кабінет/інтерфейс адміністратора.
- **Out-of-Scope (Винесено за межі):** Онлайн-еквайринг (платіжні шлюзи); інтеграція з телефонією/SMS-шлюзами; доставка ігор кур'єром; програма лояльності з кешбеком.
