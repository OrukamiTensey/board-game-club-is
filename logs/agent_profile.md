# Профіль кодингового агента (SDD Tooling Profile)

- **Назва інструменту / модель:** Claude Code / Cursor (LLM: Claude 3.7 Sonnet / GPT-4o)
- **Клас інструменту:** Інтерактивний агент розробки з доступом до файлової системи та терміналу (Agentic Coding CLI/IDE Assistant).
- **Спосіб доступу до репозиторію:** Прямий доступ до локального робочого каталогу через IDE / CLI.
- **Дозволені операції в середовищі:**
  - Аналіз структури репозиторію та вмісту файлів специфікацій.
  - Генерація та редагування коду/документації на основі запитів.
  - Виконання термінальних команд (статичний аналіз, тести) за погодженням оператора.
- **Обмеження:** Всі зміни підлягають обов'язковій валідації через `git diff`; заборонено прямий пуш без ручного рев'ю.
