# Протокол контрольної точки: GIT-GATE-01

## 1. Контекст конфлікту
- **Гілка агента (`feature/agent-rental-terms`):** коміт агента пропонував жорстку заставу 100% ринкової вартості.
- **Гілка `main` (людина):** коміт запроваджував фіксовану пільгову заставу 500 грн для постійних гостей.

## 2. Критерій вирішення (SDD Reference Standard)
Рішення прийнято не за часовою міткою і не за пріоритетом людини перед ШІ, а на основі аналізу комерційних ризиків та цілей системи:
- Фіксована застава створює касовий розрив у разі втрати колекційних ігор (наприклад, вартістю > 3000 грн).
- Виключно 100% застава блокує потік оренди для студентів і випадкових гравців.

## 3. Прийняте рішення
Синтезовано гібридне правило: базова застава залежить від оціночної вартості гри, але підтримує знижені коефіцієнти для верифікованих членів клубу.

## 4. Питання на опрацювання для Лабораторної роботи №2 (SRS)
- Класифікація ігор за категоріями ризику (A/B/C) та формула розрахунку розміру застави.
- Механізм верифікації статусу «Постійний член клубу».
