# Інформаційна система клубу настільних ігор (BoardClub IS)

> **Дисципліна:** Проєктування інформаційних систем  
> **Лабораторна робота №1:** Організація репозиторію SDD-проєкту, версіювання артефактів та вирішення колізій людина–агент  

---

## 1. Загальний опис проєкту
Проєкт присвячений розробці архітектури та реалізації інформаційної системи клубу настільних ігор. Система автоматизує:
* Облік фонду фізичних копій ігор та їхньої комплектності.
* Бронювання ігрових столів і зон у залі закладу.
* Сервіс прокату настільних ігор додому з урахуванням заставної політики.
* Проведення відкритих ігротек, турнірів та навчання новачків гейм-майстрами.

---

## 2. Організація репозиторію за стандартом SDD
Репозиторій організовано відповідно до моделі збереження артефактів Spec-Driven Development (SDD):

```text
board-game-club-is/
├── spec/       # Специфікації вимог, моделі предметної області та архітектурні рішення
│   └── system_intent.md       # Початковий опис задуму системи
├── tests/      # Тестові набори (модульні, інтеграційні, перевірка бізнес-правил)
├── src/        # Вихідний код системи та скрипти конфігурації
├── docs/       # Документація користувача, інструкції адміністратора
├── logs/       # Журнали роботи з кодинговим агентом та аудиту контрольних точок
│   ├── agent_profile.md       # Профіль та операційний скоуп кодингового агента
│   └── git_gate_decision.md   # Протокол вирішення конфлікту GIT-GATE-01
└── README.md   # Звітний огляд проєкту та стану артефактів
